DevNet Deployment Flow

Push to main → GitHub Actions build (cached npm) → atomic Nginx deploy on Dellbuntu

Prerequisites

  • • Self-hosted runner on Dellbuntu (home labels)
  • • Passwordless sudo for gh-runner
  • • Nginx project include path configured

Inputs → Outputs

  • • Input: commit on main
  • • Artifact: dist/ (+ patched modular.conf)
  • • Output: static site at /var/www/devnet/dist

Tools & Integrations

  • • GitHub Actions (build + artifact)
  • • Self-hosted runner (Dellbuntu)
  • • Nginx (path-mounted /devnet/)

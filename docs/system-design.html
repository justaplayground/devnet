DevNet System Design

Self-hosted SPA + Fastify API on Docker Compose network devnet

Request path

  • • Browser → Host Nginx /devnet/
  • • Host proxies to edge :8088
  • • Edge serves SPA assets
  • • /devnet/api → Fastify via Docker DNS

Scaling

  • • Stateless API: compose --scale api=N
  • • Edge resolves api via 127.0.0.11
  • • Postgres + Redis stay single instances
  • • Volumes persist data across restarts

Data layer

  • • PostgreSQL 16 plain SQL migrations
  • • Redis: session sid + feed/stats cache
  • • Admin seeded from env on boot
  • • No Supabase / external BaaS
